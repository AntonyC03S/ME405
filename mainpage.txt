/** @mainpage ME 405 Term Project 

@section intro_sec Overview

This documentation describes the software for a Romi line-following robot
developed for **ME 405**. The robot uses:

- DC motors with PWM + direction drivers
- Quadrature encoders on each wheel
- A BNO055 IMU for heading and yaw-rate
- A reflectance line sensor array
- A PID controller and state observer for control and estimation

The goal of the project is to follow a line smoothly and robustly while
demonstrating good embedded software structure and documentation.

@section hw_sec Hardware

@image html romi_top_view.png "Romi robot with sensors and electronics" width=400px

The main hardware components are:

- Pololu Romi chassis
- MicroPython-capable microcontroller (e.g. Pyboard)
- Motor driver boards
- Line sensor array
- BNO055 IMU

@section sw_sec Software Structure

The code is organized into two main parts:

- **Drivers** (in the `_Driver` folder)
  - Motor driver (`Motor`)
  - Encoder driver (`Encoder`)
  - IMU driver (`IMU`)
  - Line sensor array (`Line`)
  - State observer (`RomiObserver`)
  - PID controller (`Controller`)

- **Tasks** (in the `_Task` folder)
  - Motor control task
  - Line-following / control loop task
  - IMU and encoder update tasks
  - Any additional high-level behaviors

@section nav_sec How to Use This Documentation

Use the navigation panel on the left:

- **Classes** – object-oriented interfaces such as `Motor`, `Encoder`,
  `IMU`, `Line`, `Controller`, and `RomiObserver`
