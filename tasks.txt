/** @page tasks Task Modules
@brief Overview of the real-time task files used in the Romi project.

This page summarizes the main task files that run on the Romi robot.
Each file typically contains a cooperative task (or set of tasks) that
runs in the scheduler loop.

@section task_list Task Files

- `bluetooth.py`  
  Handles Bluetooth communication with an external device (such as a PC
  or phone). Typically used for:
  - Sending debug/status information
  - Receiving commands (start/stop, mode selection, tuning values, etc.)

- `Data_Task.py`  
  Manages shared data structures used by multiple tasks. This may include:
  - Sensor readings (line sensors, IMU, encoders)
  - State estimates
  - Control outputs and flags
  It often acts as a central place to log or buffer data.

- `Encoder_Task.py`  
  Reads the quadrature encoders and updates wheel position/velocity
  information using the `Encoder` driver. This task provides:
  - Periodic calls to `Encoder.update()`
  - Stored values for wheel angle, distance traveled, and speed

- `Main1.py`  
  Main entry point / scheduler setup file. Responsibilities usually include:
  - Initializing hardware drivers and tasks
  - Creating shared data objects
  - Running the main cooperative scheduler loop

- `Motor_Task.py`  
  Controls the motors using the `Motor` driver (and often the PID
  `Controller`). This task:
  - Reads setpoints (desired speed or position)
  - Applies control laws (e.g., PID)
  - Calls `Motor.set_effort()` for each motor

- `State_Estimation_Task.py`  
  Runs the state estimation logic using the `RomiObserver` (or related
  estimation code). It typically:
  - Reads IMU and encoder measurements
  - Calls the observer `step()` method
  - Stores the estimated state `[wL, wR, s, psi]` for other tasks to use

- `UI_Task.py`  
  Handles user interaction with the robot. Depending on your setup, this
  may include:
  - Reading buttons or switches
  - Updating an OLED / LCD / serial menu
  - Changing modes (idle, line follow, test, debug) based on user input

@section usage How These Tasks Work Together

In the complete system, these tasks cooperate to:

1. Read sensors (encoders, IMU, line sensors).
2. Estimate the robot state.
3. Compute motor commands using control algorithms.
4. Send debug/telemetry data over Bluetooth.
5. Provide a user interface to configure and start/stop the robot.

*/
