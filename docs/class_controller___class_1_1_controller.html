Detailed Description

PID feedback controller.

Implements a real-time PID controller with anti-windup and output saturation.

The controller outputs a value limited to the range [-100, 100], making it suitable for motor effort commands in your robot.

Features:

  • Proportional, integral, and derivative terms
  • Derivative on measurement error
  • Anti-windup integral behavior
  • Automatic output saturation
