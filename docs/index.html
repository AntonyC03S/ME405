ME 405 Term Project

Overview

This documentation describes the software for a Romi line-following robot developed for ME 405. The robot uses:

  • DC motors with PWM + direction drivers
  • Quadrature encoders on each wheel
  • A BNO055 IMU for heading and yaw-rate
  • A reflectance line sensor array
  • A PID controller and state observer for control and estimation

The goal of the project is to follow a line smoothly and robustly while demonstrating good embedded software structure and documentation.

Hardware

Romi robot with sensors and electronics

The main hardware components are:

  • Pololu Romi chassis
  • MicroPython-capable microcontroller (e.g. Pyboard)
  • Motor driver boards
  • Line sensor array
  • BNO055 IMU

Software Structure

The code is organized into two main parts:

  • Drivers (in the _Driver folder)
    • Motor driver (Motor)
    • Encoder driver (Encoder)
    • IMU driver (IMU)
    • Line sensor array (Line)
    • State observer (RomiObserver)
    • PID controller (Controller)
  • Tasks (in the _Task folder)
    • Motor control task
    • Line-following / control loop task
    • IMU and encoder update tasks
    • Any additional high-level behaviors
