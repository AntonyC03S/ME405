Detailed Description

Quadrature encoder interface.

Decodes a quadrature encoder using a hardware timer in ENC_AB mode.

The encoder uses a 16-bit timer configured in encoder mode and keeps track of:

  • Total position (in ticks)
  • Time between updates
  • Velocity

Update the encoder state.

This method must be called periodically in the main loop to keep position and velocity up-to-date.
